# Cold-tolerance-analysis-of predatory-mites
Analysis of cold tolerance data from Amblydromalus limonicus and Iphiseius degenerans to determine their establishment potential in temperate ecological zones.

#Overview
This repository contains R scripts used to analyze cold tolerance data for two predatory mites _Amblydromalus limonicus and Iphiseius degenerans_. This research was conducted in collaboration with the Swedish University of Agricultural Sciences(SLU) and has led to the licensing of _Iphiseius degenerans_as asafe biological control agents in Sweden.

#What this analysis does
Cleans and processes raw survival data from cold exposure experiments
Calculates lethal temperature thresholds (LT50)
Performs statistical comparison between species and treatmnets
Generates publication ready figures\
